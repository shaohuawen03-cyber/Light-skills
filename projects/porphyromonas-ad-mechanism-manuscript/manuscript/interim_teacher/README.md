# Interim teacher-submission package / 阶段性导师提交包

Version: v3.1.0  
Date: 2026-08-14

## Purpose

This folder contains a deliberately shorter stage-deliverable for initial supervisor review. It summarizes the current scientific question, aggregate funnel, twelve-sequence set, source-reported docking ranking, limitations and next steps without reproducing the full v3.0.0 discussion and 53-reference corpus.

本目录为首次提交导师的阶段性简稿，内容有意缩短，仅保留研究问题、汇总漏斗、12条序列、来源报告对接排序、主要局限和下一步。完整稿仍在原有主稿路径维护，不被本简稿覆盖。

## Files

- `interim_teacher_en.md` / `.docx` — standalone English short SCI draft.
- `interim_teacher_zh.md` / `.docx` — standalone Chinese short SCI draft.

The two DOCX files are separate rather than bilingual. Both use the same numerical results, two tables, one figure and a 20-reference stage bibliography.

## Evidence boundary

The short format does not upgrade evidence. External sequence and Vina values remain source-reported; docking was not independently reproduced. The package does not establish current-cohort expression, disease specificity, BBB transport, toxicity, metal chemistry, AChE binding/function or AD causality.
