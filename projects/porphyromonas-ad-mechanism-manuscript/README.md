# 牙龈卟啉单胞菌相关肽与阿尔茨海默病机制研究论文

## 项目目标

以“材料与方法及结果_机制研究版”为主要依据，撰写中英文对照的原创研究型 SCI 论文。

## 目录说明

- source_materials：用户提供的原始 DOCX 和 PDF 材料
- SHA256SUMS.txt：原始材料的 SHA-256 完整性校验值
- manuscript：后续生成的中英文论文
- evidence：后续生成的结果与论断证据台账
- references：后续生成的参考文献核验记录
- quality_reports：后续生成的写作和一致性检查报告

## 原始材料保护

原始材料只用于读取和版本存档。后续生成结果不会直接覆盖 source_materials 中的文件。
