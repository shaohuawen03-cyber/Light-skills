# SCI manuscript revision v2 / SCI 稿件重构第二轮

本轮不以“语言润色”为起点，而按科研链条逐级重构：

1. 选题与创新审查：`01_topic_brainstorming.md`
2. 文献检索与查新：待 Stage 1 路线确认后执行
3. 领域综述与证据综合：待执行；用于重写 Introduction/Discussion，不把原创研究改成综述论文
4. 全流程研究方案：待执行
5. 统计审查：待行级/受试者级数据后执行；聚合计数只做描述审计
6. 科学绘图：待统计证据和图—claim 绑定后执行
7. Nature-style scientific writing：待证据链冻结后重写
8. 学术润色：待科学内容定稿后执行
9. 选刊、格式与投稿包：必须由用户选择期刊；系统不代替用户实际投稿

对应的 Light 技能：

- Scientific Brainstorming → `light-idea-generation` + `light-idea-critique`
- Nature Academic Search → `light-literature-search` + `light-citation`
- Literature Review → 文献证据综合模板与 claim–citation 审查
- Academic Research Suite → `light-orchestrator` + `light-research-plan`
- Nature Statistics → `light-result-analysis` + `light-research-ethics`
- Scientific Visualization → `light-figure`
- Nature Writing/Polishing → `light-paper-writing` 的论证、机检与离线润色链
- Submission → `light-typesetting` + `light-venue-matching`；最终选刊和提交权属于用户

原则：不能用语言包装替代缺失的数据、统计单位、验证实验或机制证据。
