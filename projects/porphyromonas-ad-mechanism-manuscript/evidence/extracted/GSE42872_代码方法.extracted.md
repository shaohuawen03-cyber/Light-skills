1.2  为什么用 limma 而不是 DESeq2

<!-- paragraph:12 -->
这是本流程最关键的方法学判断。GSE42872 是芯片数据，series matrix 中存放的是 RMA 归一化后的 log2 荧光强度（连续型，实测值域 2.67–14.56），而非测序 reads 计数。DESeq2 与 edgeR 的负二项模型建立在计数数据的均值—方差关系之上，将连续型强度值输入其中在统计上不成立。芯片数据的标准方法是 limma 的线性模型配合经验贝叶斯方差收缩。

## [table:2]
|  | RNA-seq | 芯片（本数据） |
| --- | --- | --- |
| 数据 | 整数 counts | RMA log2 强度 |
| 分布假设 | 负二项 | 近似正态 |
| 适用方法 | DESeq2 / edgeR | limma lmFit + eBayes |

3.3  limma 差异表达

<!-- paragraph:55 -->
每组仅 3 个重复，残差自由度为 4，单基因方差估计极不稳定。limma 的经验贝叶斯方法（Smyth 2004）跨基因借用信息解决这一问题：

<!-- paragraph:56 -->
① 逐基因线性模型       →  每基因 σ²g（df = 4）

<!-- paragraph:57 -->
② fitFDist 估计先验    →  s₀² = 0.01080,  d₀ = 3.000

<!-- paragraph:58 -->
③ 后验方差（加权平均）  →  s²post = (d₀·s₀² + df·σ²g) / (d₀ + df)

<!-- paragraph:59 -->
④ moderated t          →  t = β / (SE · √s²post)

<!-- paragraph:60 -->
有效自由度 = df + d₀ = 4 + 3 = 7

<!-- paragraph:62 -->
自由度由 4 提升至 7，相当于在不增加样本的前提下获得约 3 个自由度的额外信息。这是 limma 在小样本场景下的核心优势。

<!-- paragraph:63 -->
表 3-1  差异表达参数

## [table:5]
| 参数 | 取值 | 依据 |
| --- | --- | --- |
| 设计公式 | ~ group | 单因素两水平 |
| 参考水平 | Control | logFC 为正表示处理组上调 |
| 多重检验 | Benjamini–Hochberg | 基因组尺度标准做法，控制 FDR |
| FDR 阈值 | 0.05 | 常规 |
| |log2FC| 阈值 | 1.0（2 倍变化） | 统计显著与生物学意义双重约束 |

<!-- paragraph:65 -->
仅用 p 值筛选时有 9,877 个探针达到 padj<0.05（约占全部探针 30%），叠加 2 倍变化要求后收敛至 1,303 个，后者才是值得进一步解读的集合。

<!-- paragraph:74 -->

## [table:8]
| 指标 | 数值 |
| --- | --- |
| 可对齐基因数 | 17,239 |

| logFC 逐位相同（<1e-9） | 17,202 / 17,239 = 99.79% |
| moderated t 相关系数 | 0.995569 |
| Top50 基因重叠 | 42 / 50 |

<!-- paragraph:76 -->
99.79% 的 logFC 精确到小数点后 9 位完全一致。少数不一致条目源于用 AveExpr 反查探针时的匹配歧义（数值相撞导致配错行），并非计算差异；改用官方 PROBEID→SYMBOL 映射即可消除。

8.2  受限于数据的分析

## [table:12]
| 分析类型 | 受限原因 |
| --- | --- |
| WGCNA 共表达网络 | 需 15–20 以上样本，本数据仅 6，结果为噪音 |
| 生存分析 / 预后模型 | 细胞系体外实验，无患者随访数据 |
| 免疫浸润反卷积 | 纯细胞系培养，不含免疫细胞，结果无生物学意义 |
| 机器学习分类器 | n=6 必然过拟合，无法有效交叉验证 |
| 可变剪接分析 | GPL6244 为基因水平芯片，无外显子级探针 |
| eQTL 分析 | 无基因型数据 |

<!-- paragraph:100 -->
关于重复数：Schurch 等（RNA 2016）的系统评测显示，n=3 时各类差异表达工具普遍漏检 20–40% 的真阳性。因此本流程给出的差异基因数量属保守估计。所幸本实验效应量极大（CD36 上调 55 倍，DUSP6 下调 18.5 倍），主要信号在 n=3 条件下已能稳定检出。
