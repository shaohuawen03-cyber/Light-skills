# Revision v3 — Stage 8: bilingual language polishing / 双语语言润色

Date: 2026-08-12

## Parallel-text rules

- English and Chinese versions retain the same top-level scientific sequence: Abstract, Introduction, Materials and Methods, Results, Discussion, Conclusions, Declarations and References.
- Counts, denominators, sequence strings, score values, accession identifiers, commit identities and claim boundaries are synchronized.
- The bilingual manuscript presents each top-level section in English followed by Chinese and uses one shared reference list.

## Terminology decisions

- provenance-aware → 基于来源边界 / 保留来源边界
- periodontitis-cohort branch → 牙周炎队列分支
- model-positive / BBB-high → 模型阳性 / BBB高分
- source-reported → 来源报告 / 外部来源报告
- not independently reproduced → 未独立复现
- hypothesis-generating → 假设生成
- peripheral anionic site (PAS) → 外周阴离子位点（PAS）

## Integrity edits

Causal verbs were replaced with bounded wording where the data support only screening or association. Docking “binding” language was replaced by “score,” “ranking,” or “placement reported by the external source.” SD is never called reproducible run-to-run variation.

## Remaining human task

A domain-fluent bilingual author must verify nuanced terminology, journal house style, names/affiliations, and the final machine-assisted translation disclosure.
